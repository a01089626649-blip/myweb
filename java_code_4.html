리스트에서 특정 문자열 찾기 (난이도: 중)
설명: 문자열 리스트(words)와 찾고 싶은 문자열(target)을 매개변수로 받아, 리스트 안에 target이 존재하면 true, 없으면 false를 반환하는 containsWord(ArrayList<String> words, String target) 메서드를 작성하세요.

boolean containsWord(ArrayList<String> words, String target) {for (int i = 0; i < words.size(); i++) {if (words.get(i).equals(target)) {return true;}}return false;}

리스트에서 특정 조건의 수만 합하기 (난이도: 중)
설명: 정수형 리스트(nums)를 매개변수로 받아, 리스트의 모든 원소 중 50 이상인 수들만 골라 그 합을 구하여 반환하는 sumOverFifty(ArrayList<Integer> nums) 메서드를 작성하세요.

int sumOverFifty(ArrayList<Integer> nums) {int sum = 0;for (int i = 0; i < nums.size(); i++) {if (nums.get(i) >= 50) {sum += nums.get(i);}}return sum;}
