Java이론설명!!!

클래스 Java 클래스는 객체를 만들어내기 위한 상태(변수)와 행위(메서드)를 정의한 '설계도'입니다. 이를 바탕으로 new 연산자를 통해 실제 메모리에 구현된 결과물이 바로 '객체(인스턴스)'입니다.
배열 배열은 같은 타입의 데이터 여러 개를 메모리에 연속적으로 저장하여 하나의 변수로 관리하는 '상자 묶음'입니다. 생성 시 크기가 고정되며, 인덱스(0번부터 시작하는 번호)를 이용해 각 데이터에 빠르게 접근할 수 있습니다.
인터페이스 Java 인터페이스는 클래스들이 공통으로 구현해야 하는 행위를 정의한 '표준 규격서(또는 계약서)'입니다. 구현 코드가 없는 추상 메서드로 이루어져 있어, 서로 다른 클래스들이 동일한 방식으로 동작하도록 강제하고 연결하는 역할을 합니다.
추상클래스 Java 추상클래스는 구체적인 자식 클래스들의 공통적인 특징을 모아둔 '미완성 설계도'입니다. 자신은 직접 객체를 만들 수 없으며, 자식 클래스가 이를 상속받아 미완성된 부분(추상 메서드)을 반드시 채워 완성하도록 강제합니다.
리스트 Java 리스트(List)는 데이터의 저장 순서를 유지하며 여러 값을 중복해서 저장할 수 있는 '동적 배열 상자'입니다. 고정된 크기만 가질 수 있는 일반 배열과 달리, 데이터가 늘어나거나 줄어들 때 상자의 크기가 자동으로 조절되어 다루기 편리합니다.
맵 Java 맵(Map)은 데이터를 키(Key)와 값(Value)의 쌍으로 묶어서 저장하는 '사전 형태의 저장소'입니다. 중복될 수 없는 고유한 키를 열쇠처럼 사용하여, 그 키에 연결된 실제 데이터를 아주 빠르게 찾아낼 수 있습니다.
