배열 탐색하기 (난이도: 중)
설명: 정수형 배열(scores)을 매개변수로 받아 배열 안의 모든 점수의 평균(double)을 계산하여 반환하는 average(int[] scores) 메서드를 작성하세요. (단, 평균 계산 시 소수점까지 나오도록 double 타입 변환에 주의하세요.)

double average(int[] scores) {int sum = 0;for (int i = 0; i < scores.length; i++) {sum += scores[i];}return (double) sum / scores.length;}

배열에서 짝수의 개수 세기 (난이도: 중)
설명: 정수형 배열(numbers)을 매개변수로 받아, 배열에 담긴 숫자들 중 짝수(2로 나누어떨어지는 수)의 개수를 세어 그 개수를 반환하는 countEvens(int[] numbers) 메서드를 작성하세요.

int countEvens(int[] numbers){int count = 0;for (int i = 0; i < numbers.length; i++) {if (numbers[i] % 2 == 0) {count++;}}return count;}
