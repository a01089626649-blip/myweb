조건문/반복문연습!!!

나이가 20세 이상이면 "성인입니다"를 출력하는 조건문(나이변수 : age)

if (age >= 20) {
System.out.println("성인입니다");}

등급이 "VIP"이고 금액이 10만원 이상이면 "무료" 출력 (등급: grade, 금액: price)

if (grade.equals("VIP") && price >= 100000) {System.out.println("무료");}

1부터 10까지 더해서 변수에 누적 (합계변수: sum)

for (int i = 1; i <= 10; i++) {sum += i;}

루프를 돌다가 숫자가10되면끝(숫자변수: num)

while (true){if (num == 10) {break;}num++;}
